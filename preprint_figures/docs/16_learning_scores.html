Learning scores

Three integer scores per cell — habituation, sensitization, anticipation — that count how often a cell exhibited the behavior across the 3-train, 5-stim DMSO protocol. The headline test for whether single cells "learn" the train.

How to read this figure

  1. Each histogram is a per-cell score 0–9 (0–3 for anticipation).
  2. A peak at 0 = no learning. A peak at high scores = consistent learning.
  3. Compare height vs width metrics — different aspects of learning.
  4. Anticipation: positive vs negative direction matters.
Purpose

Quantify learning-like behavior at the single-cell level

Population-mean traces (in dff) and per-stim violins (in response_violins) show whether the population habituates or sensitizes. This script asks: does each individual cell habituate / sensitize / show anticipation? It assigns a discrete score to each cell, then plots the population distribution of those scores. A bimodal distribution would suggest learners vs non-learners. A peak at 0 means no cell shows the behavior consistently.

DMSO experiments only (response_direction = "increase"). Designed for the 3-train × 5-stim protocol that C2C12 and PC3 use.

Inputs

What it reads from state

  • state["corrected_lum"][exp][ch] — bg-corrected per-cell traces.
  • cfg["stim_frames"][ch] — must contain a multiple of LEARNING_STIMS_PER_TRAIN (= 5) stims, organized as 3 trains × 5 stims = 15 total.
  • Per-cell response heights and widths — computed exactly as in response_violins using per_cell_response_delta.
  • Baseline noise estimate — per-cell std of frame-to-frame deltas in non-stim periods.
Method · habituation

"New minimums per cell across 3 trains × 4 increments"

# For each train of 5 stims:
running_min = response[stim 0]
score = 0
for s in [1, 2, 3, 4]:
    if response[stim s] < running_min:
        score += 1
        running_min = response[stim s]

# Total habituation score = sum across 3 trains.
# Max = 3 × 4 = 12 (each subsequent stim is a new min)
# Min = 0 (responses never decrease within a train)

Computed once for the height metric and again for the width metric. NaN responses are skipped (don't increment, don't update running min).

Method · sensitization

"New maximums per cell across 3 trains × 4 increments"

# Symmetric to habituation, but tracks running_max:
for s in [1, 2, 3, 4]:
    if response[stim s] > running_max:
        score += 1
        running_max = response[stim s]

# Same range: 0..12 total across 3 trains.

A cell with monotonically increasing responses scores 12. A cell with monotonically decreasing responses scores 0 here (and ~12 on habituation).

Method · anticipation

"|response| > typical fluctuation, 10 min after last train peak"

  1. Baseline fluctuation. Per-cell std of frame-to-frame deltas in non-stimulation periods (more than ~10 min away from any stim). This is the cell's intrinsic noise level.
  2. Peak timing per train. For the last stim of each train, find the median peak frame across cells (within the response window).
  3. Anticipation window. 10 minutes after that train-end peak. We're asking: in the post-train rest period, does the cell pre-emptively respond as if expecting another stim?
  4. Score logic. If the cell's response in the anticipation window has magnitude > baseline fluctuation, increment a score. Track signed direction:
    • Positive score — same direction as the stim (e.g. luminosity goes up, like during DMSO). Predictive behavior.
    • Negative score — opposite direction. Could indicate rebound or adaptation overshoot.
  5. Max = 3 (one per train).

What the cell biology says

Expected trends · interpretation

No-learning population

Habituation and sensitization both peak at 0 — most cells don't establish either pattern within a train. Anticipation pos and neg are both ~0. The default expectation if cells don't form lasting state changes between stims.

Habituation-dominant population

Habituation distribution shifted right (peak at 6+); sensitization peaked at 0. Cells progressively reduce response within trains. Classic "novelty wears off" behavior.

Sensitization-dominant population

Sensitization shifted right; habituation peaked at 0. Cells amplify response within trains. Less common but biologically meaningful (e.g. signaling-primed cells).

Mixed

Both habituation and sensitization have non-trivial mass at moderate scores, possibly with bimodality. Suggests two populations with different rules. Compare to clustering to see if these match phenotypic clusters.

Positive anticipation

Anticipation green bars to the right of red bars: cells respond pre-emptively in the same direction as the stim 10 min after the last train. Suggests timing-aware behavior — the population "expects" continuation.

Negative anticipation

Red bars dominate green. Cells go opposite to the stim direction in the post-train window. Could be rebound, adaptation overshoot, or homeostatic correction.

Watch out

Pitfalls

The biology this measures is fragile

Score saturation. A score of 12/12 means every increment hit a new extremum. With only 4 increments per train, the resolution is coarse. A cell with very small consistent decreases scores the same as one with large decreases.

NaN responses bias scores down. Missing data prevents incrementing the score, but doesn't fail the score — so cells with missing frames look less responsive than they are. The dff and time_traces pages can show whether NaNs are common.

Train structure assumption. The script expects a multiple of 5 stims. If a stim is missed by stim resolution (e.g. clipped by time_window_minutes), the train alignment shifts and scores become meaningless.

Anticipation 10-min window is hard-coded. If the next train starts before 10 min, the anticipation window overlaps the next stim and detects the real stim, not anticipation. If trains are spaced more than 10 min apart, the window may be a quiet period that's too early to see anticipatory dynamics.

Baseline fluctuation is per-cell. Cells with very wide intrinsic noise have high thresholds and rarely score positive on anticipation, even if they have real but moderate-magnitude pre-emptive responses.

No statistical test. The histograms are descriptive, not inferential. There's no null model for "what would scores look like by chance" — so a peak at score 3 isn't tested against random fluctuation. A future improvement would be a permutation test on scrambled stim labels.

DMSO-only. The script silently does the wrong thing (or crashes) on non-DMSO experiments. NRK acid is excluded by the response-direction check.
