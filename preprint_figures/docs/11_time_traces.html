Time traces

Every tracked cell, every frame, plotted as one line. The most direct view of the data: it shows you what each cell did and how the population behaved across stims. Two variants — annotated, and clean for publication.

How to read this figure

  1. Look for traces that visibly rise (or fall) at stim shading.
  2. Estimate population heterogeneity by trace spread.
  3. Note any obvious outlier traces — are they real?
  4. Compare the shading variant to the clean variant.
Purpose

The most honest view of the data

This is "show me the data" before any aggregation, normalization, or model. Every other figure in this pipeline is a summary of these traces. Use it to (a) confirm that cells are being tracked, (b) spot dropouts and tracking failures, (c) gauge raw response sizes, and (d) compare overall traces across channels in the same experiment.

Inputs

What it reads from state

  • state["corrected_lum"][exp][ch] — per-cell time series, dict of {cell_id → {"fN": value | None}}.
  • cfg["stim_frames"][ch] — frame indices for stim shading.
  • cfg["channels"] — list of channels to plot side-by-side.
  • state["real_setpoint_min"][exp][ch] — only for NRK; minutes-since-start of the second setpoint event.
  • Time axis: built from state["frame_minutes_src"] via frames_to_min().
Method

What the script does

  1. For each experiment, build a 1 × N_channels figure (subplots side-by-side, shared y-axis).
  2. For each channel:
    • Iterate corrected_lum[exp][ch].items(). For every cell:
      • Pull the (frame_index, value) pairs, drop Nones, sort by frame.
      • Convert frame indices to minutes via frames_to_min.
      • Plot as a line: per-cell color from a colormap (viridis-like), α=0.7, linewidth ≈ 1.2× nominal.
    • Title with channel name + cell count + stim count.
  3. For the annotated variant: call stim_spans_min() and draw_stim_spans() to fill stim regions with red shading at α=0.18. Add a vertical dotted line for the real setpoint (NRK only).
  4. For the clean variant: same plot, no stim shading. Setpoint marker is still drawn if present.
  5. Remove top/right spines for a publication look. Save both variants.

What the cell biology says

Expected trends · interpretation

Healthy responder

Trace rises (DMSO) or falls (acid) sharply during stim shading, then partially recovers between stims. Across the train, peaks may shrink (habituation) or grow (sensitization).

Non-responder

Flat trace with noise comparable to baseline period. Possibly slow drift, but no obvious stim-locked feature. Often the majority of cells.

Tracking dropout

Trace ends partway through the experiment, or has gaps. The cell exited the field of view, was lost by the tracker, or the segmentation failed.

Outlier trace

One or two cells with luminosity 5–10× the rest. They auto-scale the y-axis, making the rest look flat. If real, these are very bright cells; if not, suspect a tracking ID error (two cells merged, or a saturated pixel cluster).

Real setpoint marker (NRK)

A vertical dotted black line at the time the feedback controller switched to its second setpoint. The dynamics on either side may differ — pre-setpoint is initial stabilization, post-setpoint is steady-state.

Cross-channel similarity

For C2C12 / NRK, compare adjacent panels: are the population-level features similar across channels? If not, channel-specific imaging conditions may be at play.

Watch out

Pitfalls

What this figure hides

Y-axis auto-scaling. A single very-bright cell sets the upper bound, compressing all the others into a flat-looking band. This figure has no outlier suppression. If the population looks weirdly flat, check max trace value vs the rest.

Color cycling. Many cells → the colormap reuses similar hues. Don't try to identify individual cells from color — it's purely decorative.

Tracking discontinuity. When the upstream tracker loses a cell and re-acquires it as a new ID, the trace splits. This figure won't tell you that happened. luminosity_complete.json upstream is supposed to handle merging; verify if you see suspicious gaps.

Stim shading depends on resolution. If stim resolution picked wrong frames, the shading misaligns with the real biological response. Cross-check with the cell traces — peaks should sit near the shading.

NaN frames are interpolated for PC3. Dead-frame masking + linear fill smooths over what would otherwise be obvious artifacts. The traces look continuous even when the underlying frames were dropped. Check the bg_diagnostic col-4 trace for the original spikes.
