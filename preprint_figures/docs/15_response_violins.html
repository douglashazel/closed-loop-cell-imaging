Per-stim response violins

A violin per stimulus showing distribution of single-cell response sizes. Two metrics: amplitude (height) and duration (width). Two views: full population and responders-only. Two scopes: per-channel and pooled. Built to spot habituation and sensitization across the train.

How to read this figure

  1. Compare median (thick line in box) across stims — direction.
  2. Note the box notch — narrow = tight 95% CI on median.
  3. Half-violin shape shows the full distribution density.
  4. Scatter dots show every individual cell.
Purpose

Per-stim distributions, not just means

The mean dF/F0 in dff.html tells you the population direction and rough magnitude. This figure tells you the distribution at every individual stim, so you can see how the population's response evolves across the train. If the median trends down → habituation. If it trends up → sensitization. If the spread changes → the population's heterogeneity is shifting. The width metric adds the duration dimension: do responses get not just smaller but also shorter?

Inputs

What it reads from state

  • state["corrected_lum"][exp][ch] — bg-corrected per-cell traces.
  • cfg["stim_frames"][ch] — stim onset frames.
  • cfg["response_direction"] — controls min vs max in the response window.
  • cfg["response_window"] — frame offsets (lo, hi) after each stim.
  • Responder thresholds from responders.py — for the responders-only variant.
Method

Two metrics

Height — Δ luminosity

# For each cell c and stimulus at frame_col p:
window     = corrected_lum[c, p+lo : p+hi]
extremum   = max(window) if response_direction == "increase"
             min(window) if response_direction == "decrease"
baseline   = pre-stim mean (frames 0..first_stim)
height[c, stim] = extremum − baseline

Result: (n_stims, n_cells) matrix. NaN for stims without enough trailing frames or cells with NaN baseline.

Width — duration above threshold (in minutes)

For each cell, find the contiguous segment starting at the stim where the response stays above a threshold (or below, for "decrease"). Convert that frame count to minutes via frames_to_min. The search is capped by compute_stim_caps so the width can't extend into the next stim's window.

Violin construction

One violin per stim with three layered elements:

  • Half-violin (right side only) — KDE of the distribution.
  • Notched box (left side) — quartiles, with notch giving 95% CI on the median.
  • Jittered scatter — every individual (cell × stim) point, jittered with seed=42 for reproducibility. Lets you spot outliers.
  • Mean bar — horizontal line at the mean (across all points in the violin).

Pooled variants

If pool_channels=True AND all channels have the same number of stims, concatenate response arrays across channels to make one violin per pooled stim. Larger n → smoother distributions.

Responders-only variant

Filter to cells whose peak |dF/F0| across all stims meets the Bonferroni threshold from responders.py. Then plot the violin of luminosity deltas (not dF/F0) for that subset. Title shows responder count and threshold value.

Signal axis

lum vs dF/F0

plot_per_stimulus_response_violins and plot_amplitude_width_scatter both take a signal in {"lum", "dff"} argument. _build_signal_matrix returns either the raw corrected luminosity matrix or (mat − F0) / F0_safe; both flow through the same per_cell_response_delta machinery so the metric definitions are unchanged. When signal="dff" the width search threshold is the dF/F0 value at the stim frame (≈ 0). Filenames append _dff so both variants coexist (e.g. {ch}_response_violin_width_dff.png).

Joint distribution

Amplitude × width scatter

plot_amplitude_width_scatter emits one figure per (exp, ch, signal) with a roughly-square grid of stims, each panel showing per-cell (amplitude, width) pairs. Per-cell pairs stay aligned (no independent NaN dropping) — only cells where both metrics are defined are plotted. When a stim has more than 200 valid cells the scatter falls back to a hexbin with a viridis colour-bar so density stays legible; otherwise it draws individual points. Output: {ch}_amplitude_width_scatter_lum.png and {ch}_amplitude_width_scatter_dff.png.

NRK width baselines

Three baselines, side by side

plot_nrk_width_baseline_comparison (NRK only) emits a single 1 × 3 figure per channel comparing three definitions of the response baseline used in the width measurement:

stim_value

Value at the stim frame — the current default behaviour. Same as {ch}_response_violin_width.png.

prestim_window

Mean of n_pre = 5 frames immediately before the stim (prestim_baseline_values in common/baseline_window.py). Robust to instantaneous noise at the stim frame.

nrk_setpoint

NRK hardware feedback setpoint active at the stim frame, parsed via nrk_setpoint_at_frame() from luminosity_log_channel<N>.json. Width measures how long the cell sits below the setpoint.

Output: {ch}_response_violin_width_baselines.png. The existing {ch}_response_violin_width.png is unchanged (it still uses stim_value) so existing figures remain comparable.

Per-cluster violins

Stratifying by trace cluster

plot_per_stimulus_response_violins_per_cluster reads the per-channel cluster cache (14 · clustering), aligns labels to the channel's cell IDs via align_labels_to_cells, and re-renders the height/width violin restricted to each cluster's mask. Clusters with fewer than 3 matching cells are skipped silently. Same signal switch applies. Output: {ch}_response_violin[_width][_dff]_c{k}.png. Skipped silently when no cluster cache exists for the channel.

What the cell biology says

Expected trends · interpretation

Habituation

Median height (and/or width) decreases across stims within a train, possibly resetting between trains. Classic for repeated stimulation: cells reduce response on familiar stim. Look for a downward staircase in the medians.

Sensitization

Median grows across stims. Less common in mature differentiated cells; more in proliferating or signaling-primed cells. An upward trend in the medians.

Tight violins

Narrow KDE → population is synchronized in response size. Suggests a homogeneous response phenotype. Often the responders-only variant tightens up dramatically vs the all-cells variant.

Wide violins

Broad KDE → population is heterogeneous. Some cells respond strongly, others barely. Pair with clustering to ask whether the heterogeneity is discrete or continuous.

Negative heights (for "decrease" experiments)

NRK acid: heights are negative because the response window extracts a min. Violins extend below zero. The magnitude of the median is the response size.

Width scatter increases over the train

Later stims may have noisier widths because the inter-stim cap shortens or a previous response hasn't fully decayed before the next stim. Pay attention to the cap → in extreme cases, the width metric becomes unreliable for late stims.

Watch out

Pitfalls

What this figure can mislead about

Response window choice. A narrow window (+1, +2) may miss slow responders entirely. A wide window may catch baseline noise after the response ended. The default (+1, +8) is reasonable for ~1 Hz frame rate but isn't sensitivity-checked.

Width threshold logic. The width metric uses compute_stim_caps which depends on inter-stim spacing. Irregular stim spacing (NRK feedback) makes width comparisons across stims ambiguous.

Baseline drift. Heights are measured against baseline, which is a fixed pre-experiment estimate. If baseline drifts downward over the experiment, later stims appear to have larger heights even with identical biological responses.

Saturation. If cells saturate at the detector's max value, response heights underestimate true response. The violin's upper tail gets clipped to a hard ceiling. Look for unusual flat tops on early stims.

Pooling assumption. Pooled violins assume channels report the same biological process. Pooling across imaging channels with different reporters or different cell types is misleading. C2C12 / NRK channels are usually safe; cross-experiment pooling is not.

NRK setpoint can fall outside any region. nrk_setpoint_at_frame first looks for a region containing the stim frame; if none matches, it falls back to the nearest region by edge distance. The width measurement is still computed but is now anchored to a setpoint that wasn't actually active at the stim — flag any obviously-out-of-bounds stims rather than trusting the panel blindly.

Per-cluster panels need the cluster cache. {ch}_response_violin[_width][_dff]_c{k}.png reads bg_cache/clusters/<exp>__<ch>.pkl. Run clustering.py first or these figures silently disappear.
