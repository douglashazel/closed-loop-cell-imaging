Foundations · Read first

The shared machinery

Every analysis script consumes a single state dict produced by prepare_state(). These pages explain what's in it.

00 · Pipeline

Pipeline overview

How raw frames become analysis-ready: state dict shape, caching to bg_cache/, dead-frame masking, and the order in which utilities run.

01 · Experiments

The three experiments

C2C12 (3 channels, DMSO pulses), PC3 (1 channel, flat root), NRK (4 channels, hardware-feedback acid). Channels, protocols, response direction.

02 · Bg model

Background subtraction

Per-frame degree-4 2D polynomial fit on cell-free sample points, a 25×25 candidate grid, dead-frame MAD test. The single biggest source of artifacts if it goes wrong.

03 · Stim timing

Stim frame resolution

Three sources, one precedence chain: monitoring.log → timestamps.csv → file mtimes → manual. Why cross-channel pooling sometimes can't happen.

04 · Responders

Responder thresholds

Bonferroni-corrected (α = 0.01) percentile of pseudo-stim |dF/F0| nulls, computed per (experiment, channel). The threshold most pages depend on.

Diagnostic / QC

Did the data come out clean?

10 · Diagnostic

Background diagnostic

4-column per-channel sanity check: probe frame · fitted background · corrected image · time series of background drift. Always look at this first.

18 · NRK only

NRK hardware log

Telemetry from the feedback controller: setpoint regions, acidic-pulse decisions, real-setpoint marker. NRK only; silently skipped for C2C12 / PC3.

Per-cell · Time domain

What does a single cell do?

11 · Traces

Time traces

Every cell, every frame, color-coded — with and without stim shading. Two variants per experiment: time_traces.png (annotated) and corrected_traces.png (clean for publication).

12 · dF/F0

dF/F0 normalization

(F − F0) / F0 with F0 = baseline mean. Per-channel raw + dF/F0, combined-channel mean, responder-pooled mean ± SEM, plus a C2C12-only response-magnitude histogram.

Population structure

How are cells related to each other?

13 · Spatial

Correlation vs distance

For every cell pair: Pearson r between traces vs Euclidean distance between mean positions. Linear fit + ±3 SEM band, per-channel and pooled.

14 · Clusters

Trace clustering

Z-score per cell → PCA (n=20) → UMAP (n_neighbors=15) → KMeans, with k auto-selected by silhouette. Reveals discrete response phenotypes — or shows they don't exist.

17 · Sync

Sliding correlation

Pre-filter pairs by global Pearson, then sliding-window Pearson + Spearman across the experiment. Slow, off by default. Detects population-level synchronization changes.

Stimulus response

How did cells respond to each stim?

15 · Violins

Per-stim response violins

Asymmetric half-violin + notched box + jittered points, one per stimulus. Two metrics (height, width), three variants (raw, responders-only, pooled). Look for habituation/sensitization across stims.

16 · Learning

Learning scores

Habituation (running min within train), sensitization (running max), anticipation (significant pre-emptive response). DMSO experiments only, 3 trains × 5 stims.

Where the code lives

All pages document scripts under preprint_figures/. Run the whole pipeline with ./preprint_figures/run_figures.sh from the project root. Edit the CONFIG block at the top to choose analyses and experiments. Results land in April28_preprint_results/<experiment>/.
