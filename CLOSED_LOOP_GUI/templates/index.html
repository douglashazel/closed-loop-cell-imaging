How the closed-loop system works

            
for new operators

          

          

            

              

                Frames arrive in watch_dir, get segmented by Cellpose, decisions are computed against the reference mask, and ONIX switches media on the matching channel.
              

              

                Five Python processes run in parallel, coordinated through shared directories on disk. HandleSegmentations.py segments frames with Cellpose; CreateDecisions.py compares live masked luminosity against a reference; SendDecisions.py drives ONIX to switch experiment templates.
              

              

                The Pipeline tab starts and stops the whole thing. The Segmentation tab is where you lock in the reference mask for frame 0 — nothing decides anything until you push that mask. The Experiment Log tab is your live window into what's happening.
